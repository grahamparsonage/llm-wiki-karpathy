# Evaluation Scheme for Children-Centered Language Interaction

CHI 2024 workshop paper: five-dimension framework to evaluate AI-driven robots' language competence with children (ages 3–6).

## Key findings

- Five dimensions from thematic analysis (11 families + ~30k e-commerce reviews): **interactivity**, **specificity**, **development**, **sociality**, **safety**
- Grounded in **children's agency**—children treated as independent data sources, not only via parents
- Empirical study: 6 children (3–6) with Alpha Egg GPT robot; conditions with/without parents present
- Parent presence affects observed interaction and evaluation ratings
- 16 indicators under five dimensions; mixed methods (video coding, questionnaires, interviews)
- Addresses gap: adult-oriented language benchmarks unsuitable for child-directed robot dialogue

---

## Relevance to child–AI interaction

Provides measurable child-centred criteria for voice agents; parent co-presence as evaluation variable links to mediation and distributed agency in child–AI assessment.
