# English (GB)

All wiki body text, summaries, glossaries, and analyses use **British English (en-GB)**. Direct quotations from sources may retain original spelling.

---

## Spelling

| US | GB |
|---|---|
| -ize / -ization | -ise / -isation (e.g. conceptualise, organisation) |
| -or | -our (behaviour, favour — not in fixed terms like *honouring* titles) |
| -er (center) | -re (centre) — except proper names (e.g. User-Centered Design as cited) |
| toward | towards |
| artifact | artefact |
| analyze | analyse |
| catalog | catalogue |
| capitalization | capitalisation |
| initialized | initialised |

---

## Conventions

- Use **en-GB punctuation**: single quotes for nested emphasis where appropriate; en-dash for ranges (3–17).
- Prefer **analytical** over *analytic* in wiki prose (e.g. analytical lens, analytical model).
- Keep established **HCI/CCI terms** as published (co-design, Participatory Design, sense-of-agency).
- Paper titles and author terminology: preserve original spelling; note US variants in glossary if wiki uses GB form (e.g. Criticising vs source *Criticizing*).
