# Glossary

Living reference of terms, definitions, and style conventions. Check here before using technical terms in wiki pages or outward-facing docs.

---

## Terminology

**Agency** *(canonical)*
: The ability to act intentionally to make decisions and enact them towards an outcome. In this wiki, default term when autonomy/empowerment are not deliberately distinguished.
- Preferred: `agency`, `agentic capacity`
- Avoid: using `agency` without specifying form (self / system / environment / transformative)
- See also: [[agency]], [[agency-lit-review-hal]]

**Autonomy**
: Self-governance; acting in line with one's values and goals. Distinct etymologically from agency but often synonymous in HCI sources.
- Use when citing sources that explicitly separate autonomy (e.g., data autonomy, developmental autonomy)
- See also: [[autonomy]]

**Computational Empowerment (CE)**
: Critical, informed engagement with technology's role in children's lives and society; beyond computational thinking.
- See also: [[computational-empowerment]]

**Computational Thinking**
: Understanding computing concepts and processes. Narrower than CE; do not conflate.
- Avoid: `computational empowerment` when meaning only CT skills

**Transformative agency**
: Capacity to change personal, shared, or societal matters through sustained action; fourth pillar of CE in Iivari et al. 2024.
- See also: [[transformative-agency]]

**Child–AI interaction**
: Empirical child–system engagement with data-driven/AI technologies (LLMs, recommenders, copilots, etc.).
- See also: [[child-ai-interaction]]

**Relational agency lens**
: Analytical frame for agency distributed across children, facilitators, institutions, and peers.
- See also: [[relational-agency-lens]]

**Sense-of-agency**
: Experiential feeling of causing outcomes (often micro-scale); may diverge from material control.
- See also: [[hci-agency-autonomy-four-aspects]]

**Datafication**
: Conversion of children's lives into data subjects; raises autonomy and literacy concerns.
- Related: data autonomy, digital citizenship

**Positive liberty / negative liberty** *(Voysey et al.)*
: Enabling conditions for agency vs removing barriers. Design choices depend on which view a product or study adopts.

**Protagonist role** *(CCI PD)*
: Children driving technology development and critical reflection—not only participating as testers.
- Contrasts with: design partner (Druin); aligns with CE

**Expansive learning**
: Collective creation of new practices beyond existing curricula; CHAT basis for transformative agency.

**Bildung** *(Schelhowe tradition)*
: Humanistic formation—simultaneous change in self-perception and world perception through digital engagement.

## Style Conventions

| Convention | Rule | Example |
|---|---|---|
| Default term | Use `agency` unless source distinguishes autonomy/empowerment | "supports children's agency" not "supports empowerment and agency and autonomy" |
| Specify form | Name which agency form applies in product or study docs | "agency over system (rejecting copilot suggestions)" |
| Age band | State age range when claiming developmental fit | "for ages 13–15 in formal education" |
| System vs child | Do not imply zero-sum: child loses agency when AI acts | "negotiated control with visible override" |
| CE capitalisation | `Computational Empowerment` on first mention; `CE` thereafter in CCI context | |
| Locale | British English (en-GB) for all wiki prose; see [[english-gb]] | Direct quotes keep source spelling |

## Deprecated / Avoid List

| Avoid | Use Instead | Reason |
|---|---|---|
| `user agency` (for children) | `children's agency` or `child agency` | Wiki centres child–computer interaction |
| `full autonomy` (unqualified) | balanced autonomy, configurable control | Safety and developmental constraints |
| `empowerment` as synonym without definition | [[computational-empowerment]] or specify skill/reflexivity | Politically and conceptually loaded |
| `AI agency` (ambiguous) | human agency in human–AI interaction | Avoid conflating software agents with human agency |
